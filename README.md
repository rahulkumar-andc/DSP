# Digital Signal Processing (DSP) Laboratory Manual & Code

Comprehensive practical materials, mathematical derivations, calculations, and Scilab implementation codes for DSP laboratory examinations.

## 📚 Experiments Covered

1. **Experiment 1:** Generation of Elementary Discrete-Time Sequences (Unit Sample, Unit Step, Ramp, Exponential).
2. **Experiment 2:** Linear Convolution of Rectangular Sequences (Part A: `convol()`, Part B: Nested For-Loops).
3. **Experiment 3:** First-Order Difference Equation Simulation & Theoretical Steady-State Derivation.
4. **Experiment 4:** Frequency Response (Magnitude & Phase) and Pole-Zero Stability Analysis of an IIR System.
